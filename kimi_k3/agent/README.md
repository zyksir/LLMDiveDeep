# Kimi-K3 agent notes

This directory contains historical optimization records, figures, runbooks,
and verification notes used while developing the Kimi-K3 layers. They preserve
implementation context for maintainers and coding agents; they are not user
entry points. Kernel-generation specifications live beside the kernels under
[`../kernels/specs/`](../kernels/specs/).

Start with [`../README.md`](../README.md) to run or benchmark the layers.
