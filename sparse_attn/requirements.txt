# Dependencies for the sparse / linear attention benchmarks.
#
# One-shot install (from LLMDiveDeep/, with a .venv active):
#
#     uv pip install -r sparse_attn/requirements.txt
#
# See README.md section "Environment" for the full flow.
#
# --- core -----------------------------------------------------------------
# sglang is a hard dependency: it (and its dependency set) provides the DSA
# indexer kernel (deep_gemm.fp8_mqa_logits), the FA4 dense baseline, and the
# linear-attention kernels (fla.chunk / fla.kda). PyPI ships a prebuilt
# cp310-cp313 manylinux wheel for this pin, so there is NO source build and NO
# Rust toolchain required. The [diffusion] extra matches this diffusion_inference
# tree. This pin also fixes torch==2.11.0 / triton==3.6.0 (validated on CUDA 13,
# NVIDIA B200); the torch/triton/numpy lines below are lower-bound documentation
# only -- sglang's exact pins win during resolution.
sglang[diffusion]==0.5.15.post1
torch>=2.6            # pinned to 2.11.0 by sglang; CUDA-enabled build
triton>=3.0          # pinned to 3.6.0 by sglang
numpy

# --- optional: block-sparse kernel (NOT on PyPI) --------------------------
# The Triton block-sparse FA used as the LM sparse-attention step (PART B/D/E)
# is not part of upstream sglang; it lives in an external package exposing a
# `sparse_attn/` module. Point the benchmarks at the directory that contains
# that package:
#
#     export SPARSE_ATTN_KERNELS_DIR=/path/to/kernels   # holds sparse_attn/
#
# Without it, PART B/D/E skip cleanly and the rest of the suite still runs.
